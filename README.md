
# University Website CMS Demo

A responsive, accessible, and CMS-ready university website prototype built using HTML5 and CSS3.  
This project demonstrates modern web content development practices used in higher-education environments, including accessibility compliance, structured content publishing, and SEO-friendly design.

---

## 📌 Project Overview

This project simulates a real university website with multiple content sections and reusable templates, similar to CMS platforms such as Cascade CMS or Microsoft Power Pages.

It was created to demonstrate:

- Web content publishing workflows  
- Accessibility-focused design (WCAG principles)  
- Responsive layouts for mobile and desktop  
- CMS-style reusable templates and components  
- SEO best practices  

---

## 🧱 Pages Included

- **Home** – Hero section, highlights, announcements  
- **Programs** – Academic program listing (card-based layout)  
- **News** – University announcements & updates  
- **Contact** – Accessible contact form  
- **Accessibility Statement**

---

## ♿ Accessibility Features

- Semantic HTML5 structure  
- Skip-to-content link  
- Keyboard-navigable menus and forms  
- Proper form labels and focus indicators  
- Image `alt` text  
- ARIA landmarks  
- Color-contrast friendly layout  

Designed to align with **WCAG 2.1 Level AA** guidelines.

---

## 🔍 SEO Features

- Meta descriptions  
- Proper heading hierarchy (H1–H3)  
- Semantic landmarks  
- Sitemap support  
- Clean URL structure  
- Optimized images (WebP + lazy loading)
